# Python Drawing Art

Hello there! You are viewing my collection of drawing art on PC, which is derived from various shapes, such as alphabets, patterns, animals.

All of them were implemented with **Python** language, plus **OpenCV** library.

If you wonder how all of these have been carried out, don't hesitate to check the source codes of each file above, as well as the expected output that can be found within the `Output` folder.

Note that each of these drawings have a reference to the corresponding **Pinterest** post that points to the origin of the source.
